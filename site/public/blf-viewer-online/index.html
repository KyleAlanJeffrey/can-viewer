How to open a BLF file online

  1. Open the app

    Go to app.freecanstudio.com in a desktop browser. There is nothing to install and no account to create.

  2. Open the BLF file

    Click Open Log… and choose the .blf file, or drop it anywhere on the window. It is read on your computer, compressed or not.

  3. Decode and explore

    Click Open DBC… to add the database for your bus. See every ID in Overview, read frames in Trace and plot signals in Plot.

Questions

Is my BLF file uploaded?

No. FreeCAN Studio runs in your browser: a Rust core compiled to WebAssembly reads the file on your computer. The app loads nothing from third parties, and its Content-Security-Policy makes your browser enforce that. How to check it.

What does FreeCAN Studio read from a BLF file?

The CAN traffic: every classic CAN and CAN FD frame, remote frame and error frame, with its timestamp, channel, ID and data. FreeCAN Studio is a CAN tool, so it skips the other bus types and events a BLF file can hold, such as LIN, FlexRay and Ethernet.

Do I need a DBC file?

No. Without one you still see every ID with its count, period and bit activity, and the raw frames in Trace. Add a DBC to decode signals; you can load several, each for every bus or for one bus.

How large a file can it open?

The core is built for logs of hundreds of megabytes and millions of frames. The limit is the memory your browser gives a tab, so a very large file may not fit.

Which browsers does it run in?

Current desktop versions of Chrome, Edge, Firefox and Safari. Phones and tablets are not supported. Live capture from a CAN adapter needs Chrome or Edge.

Is it free?

Yes. FreeCAN Studio is free and needs no account.
