FreeCAN Studio Pro

A paid desktop app built on the same core and the same interface as FreeCAN Studio. It is planned and not available yet: there is no price, release date or sign-up.

What Pro is planned to add

Plans can change before release.

  • Live capture Planned

    Record traffic from a CAN interface.

  • Transmit and replay Planned

    Send frames, and play a recorded log back onto a bus.

  • UDS scanning Planned

    Find the ECUs on a bus and the diagnostic services they answer.

  • Video sync Planned

    Line a video up with the log on the shared time cursor.

  • Automated signal discovery Planned

    Suggested signals for unknown messages.

  • Scripting Planned

    Automate your analysis.

FreeCAN Studio stays in the browser, free

The web app is a complete tool, not a demo: no account, no caps, no trials and no nags. Pro is a separate desktop app that runs the same interface in its own window, and like the web app it will process files on your computer.
